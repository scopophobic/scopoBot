# Changelog

## 0.1.0 preview

- Compact transparent Glitch companion, with Mochi and Pip alternatives.
- Hover reactions, interaction-only dialogue, and manual activities.
- Audio activity dancing, relevant battery badge, sustained CPU and RAM badges.
- Health panel and explicit Activity Monitor / Task Manager shortcut.
- Separate terminal mode and desktop-to-terminal switch.
- Local preferences, power modes, pack validation and hot reload.
- Mac and Windows packaging, Linux terminal checks, automated preview releases.

Early preview: Mac notarization and Windows signing are not configured. Audio detection reacts to all output activity, not specifically music. Windows native behavior must be checked on Windows; cross-compilation alone does not verify it.
